@card OSI基本参照モデル | 03-3#OSI基本参照モデル
| 層 | よく出るプロトコル |
| 7 | HTTP・SMTP・POP3・IMAP・DNS・DHCP・SNMP・NTP・SSH |
| 4 | TCP・UDP |
| 3 | IP・ICMP・ARP・RARP・IPsec・RIP・OSPF・VRRP |
| 2 | イーサネット・PPP・VLAN・STP |
(
+ VRRP — 「**冗長化**」「予備」「切り替え」（Redundancy）
+ SNMP — 「**監視**」「管理」（Management）
- DHCP — 「IPアドレスを**自動で割り当て**」
- ARP ／ RARP — 「IP→MAC」／「MAC→IP」
+ STP ／ PPP — 「**ループ防止**」／「**2点間**」
)
> 層の番号より「**何をするか**」で選ぶ。出るのはほぼ7・4・3・2層
@end

@card LANの送り方 | 03-3#LANの送り方

- CSMA/CD — 「**衝突を検出**」「**ランダム**に待って再送」（有線）
+ CSMA/CA — 「衝突を**回避**」「ACK」（無線）

@card IPアドレスの種類 | 03-4#IPv4-アドレスの種類
1. **10／172.16〜31／192.168** で始まる → プライベート
2. **224〜239** → マルチキャスト（クラスD）
3. ホスト部が**全部1** → ブロードキャスト（/24 なら .255）
4. **127** → ループバック（自分自身）
5. どれでもない → **グローバル**
> 2進数にしなくていい。上から消していくだけ。クラスの境目は 128・192・224・240
@end

@card 入口の守り（FW・IDS/IPS・WAF） | 03-5#入口を守る
外から **FW → IDS/IPS → WAF**。内側ほど中身を深く見る（多層防御）
(
- FW — 「**IPアドレス・ポート番号**で制御」
- IDS ／ IPS — 「検知して**通知**」／「検知して**遮断**」
+ WAF — 「**SQLインジェクション**・XSS」「Webアプリ」
+ どれでもない — 「**DNS・メール**」が相手 → DNSSEC・スパムフィルタ・中継禁止
)
! FW は**許可したポート（443）の中**の攻撃は止められない → だから WAF を重ねる
@end

@card 脆弱性の名札（CVE・CWE…） | 03-6#脆弱性の名札
頭のCは全部 Common。**2文字目の英単語**で見分ける
(
+ CVE — **V**ulnerability：**個別**の脆弱性の番号
+ CWE — **W**eakness：脆弱性の**種類**
+ CCE ／ CPE — **C**onfiguration：設定 ／ **P**latform：製品
+ CVSS — **S**coring：深刻度の**点数**（0.0〜10.0）
+ SCAP — これらで点検を自動化する仕組み（CWEは入らない）
)
! CVE（事件ごと）と CWE（手口の種類）の入れ替えが一番出る
@end

@card 似た名前の「コード」 | 03-6#攻撃の手口
(
+ エクスプロイトコード — 「脆弱性を**悪用**」「攻撃コード」（Exploit＝つけ込む）
+ MAC — 「**改ざん検知**」「秘密のデータ＋ハッシュ」
+ シグネチャ — 「マルウェアの**特徴**」「定義ファイル」
+ ワンタイムパスワード — 「ログインの**たびに変わる**」
)
@end

## 開発・マネジメント
@card モジュール結合度と強度 | 04-1#結合度と強度
結合度は**弱いほど**、強度は**強いほど**良い（疎結合・高凝集）
(
- 結合度（良い順） — 「です、背が今日ない」データ→スタンプ→制御→外部→共通→内容
- 強度（良い順） — 「気丈に連れて、持論案」機能→情報→連絡→手順→時間→論理→暗合
)
(
- データ・スタンプ・制御 — 「**引数**」で渡す（単一／構造体／**動作の指示**）
- 外部・共通 — 「**大域・グローバル**」（単一／構造体）
- 内容 — 「内部を**直接**参照」「**JUMP**」
)
! 引数でも**動作を指示**（フラグ）していたら制御結合
@end

@card 投資するか決める指標 | 06-2#投資するか決める指標
(
- PBP — 「**期間**」「何年で回収」→ 投資額 ÷ 毎年のもうけ
- ROI — 「利益 ÷ 投資額」「**割合**」
