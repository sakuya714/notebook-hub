@board mistakes | 誤りパターン | 選択肢のウソのつき方は数パターンしかない。どのパターンか見抜けば消せる | 誤りパターン
( 主語のすり替え
+ 監査人が**自分で直す** — 調べて勧めるまで。直すのは監査を受けた側 {{M3#監査人は促すまで}}
+ **派遣元**が指示する — 指示を出すのは**派遣先** {{T4#請負と準委任}}
+ **CA が**利用者の秘密鍵を作る — 鍵ペアは**利用者が作る**。CA は公開鍵に署名するだけ {{S1#証明書と失効}}
+ 著作権は**発注者**のもの — 請負なら**作った受注側**（契約で譲渡しない限り） {{T4#著作権は誰のもの}}
)
( 鍵の取り違え
+ 署名を**受信者の鍵**で — 署名は**送信者の秘密鍵**で作り、送信者の公開鍵で確かめる {{S1#署名と暗号化の鍵}}
+ 暗号化を**送信者の鍵**で — 隠すなら**受信者の公開鍵**
+ DKIM の署名先が **DNS** — DNS は公開鍵を置く棚。署名されるのは**メール** {{S3#DNSとメールの2×2}}
)
( 説明の入れ替え
+ 名前と説明のシャッフル — 3DCG・UML・保守・結合度は、**説明文のキーワードで答えを決めてから**名前と照合 {{H5#3DCGの技法}}
+ 隣の段階とすり替え — リスクの分析と評価、監査の手続と報告、BCP の再開と回復 {{M2#リスクアセスメント}}
- 2つの意味を持つ言葉 — 一貫性（ACID／CAP）、セグメンテーション（メモリ／市場）、保守性（RASIS／品質）、RFC、EMS、ウォークスルー（3つ）
)
( 単位のずれ
+ ビットとバイト — **× 8**。回線はビット、ファイルはバイト {{K2#解き方の型}}
+ ms と μs — 1000倍違う。M（100万）で割ると μ（100万分の1）が付く {{K2#タイマ割込み}}
- ％と小数 — 90％は 0.9 で式に入れる
- 人月の基準 — 上級者の人月か、初級者の人月か {{K1#見積り}}
)
( 言い切り・逆向き
+ 「〜なら必ず〜」の向き — 再帰なら再入（○）、再使用なら再入（×）。**内側から外側**しか言い切れない {{H4#再使用・再入・再帰}}
+ 「とは限らない」を「しない」に — 条件網羅を満たしても分岐網羅を満たす**とは限らない**（必ず満たさない、ではない） {{M1#網羅}}
- 1組の数字で「いつも」 — 差を式にして符号で確かめる {{K2#稼働率}}
)
( 古い知識（今の正解）

+ NISC — 2025年7月から**国家サイバー統括室**
- ISMS 認証 — 2018年から **ISMS-AC** が運営（JIPDEC から独立）
- RoHS — 2019年7月から**10物質**
- 下請法 — 2026年1月から**取適法**
